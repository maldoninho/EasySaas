# Test Standard

## Pirâmide mínima

- Unitários para regras puras.
- Integração para banco, API e serviços.
- E2E para fluxos críticos.
- Testes de arquitetura para limites entre Core e módulos.

## Fluxos obrigatórios

- Instalação limpa.
- Primeiro proprietário.
- Login, logout, verificação de e-mail e recuperação.
- Papéis e permissões.
- Criação, validação, ativação e rollback de módulo.
- Backup e restauração.
- Atualização do Core.

## Ambientes

CI deve validar Windows, Linux e macOS quando o estágio correspondente for implementado.

## Evidência

Uma tarefa não está concluída apenas porque o código existe. O relatório deve indicar quais comandos foram executados e seus resultados.
