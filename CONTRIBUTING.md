# Contribuição

1. Leia `AGENTS.md` e os padrões em `standards/`.
2. Trabalhe em branch separada.
3. Não altere o Core para implementar funcionalidade de produto.
4. Adicione ou atualize testes.
5. Execute `pnpm validate`, `pnpm typecheck`, `pnpm test` e `pnpm build`.
6. Descreva riscos, migrations e plano de rollback no pull request.
