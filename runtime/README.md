# Runtime

Diretórios mutáveis da instalação. Não os exponha pelo servidor web.

- `staging/`: quarentena temporária de uploads.
- `module-store/`: versões validadas e imutáveis.
- `module-archive/`: módulos retirados da execução.
- `storage/`: arquivos da aplicação.
- `backups/`: backups locais.
- `mail-outbox/`: e-mails em modo de desenvolvimento.
- `logs/`: logs locais.
