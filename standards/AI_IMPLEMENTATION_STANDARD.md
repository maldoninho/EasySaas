# AI Implementation Standard

## Antes de editar

1. Ler `AGENTS.md`.
2. Ler os padrões relacionados à tarefa.
3. Identificar arquivos autorizados.
4. Definir critérios de aceite.
5. Verificar dependências e contratos existentes.

## Durante a implementação

- Fazer mudanças pequenas e rastreáveis.
- Não inventar arquitetura alternativa.
- Não enfraquecer testes para fazê-los passar.
- Não adicionar dependências sem justificativa.
- Não ocultar falhas.
- Não declarar que algo foi testado sem executar o teste.

## Relatório obrigatório

Toda entrega deve informar:

- arquivos alterados;
- decisões tomadas;
- comandos executados;
- testes aprovados;
- limitações ou pendências reais.
